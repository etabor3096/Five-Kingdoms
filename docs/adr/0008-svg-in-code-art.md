# ADR 0008: SVG-in-code art for the MVP

Status: Accepted

## Context

All art must be original (inspired by, but not copied from, Ubisoft's UNO). There is no artist or asset budget. Cards must scale cleanly across phones and desktops, support colorblind-safe design, and highlight the round's wild rank dynamically.

## Decision

Draw cards, table and UI as SVG generated by code (react-native-svg, rendered on web through react-native-web). Each of the five suits is a "kingdom" with a distinct colorblind-safe color and a crest containing the classic suit symbol. Sound effects use free CC0 packs.

## Consequences

- Resolution-independent, themeable, tiny, and dynamic (wild highlight, state changes) with no asset pipeline.
- No dependence on third-party art or licensing, and no IP risk from imitating UNO.
- Visual richness is limited by what we can draw in code. Painted or illustrated art can replace it later behind the same card-rendering interface.
- Many SVG nodes animating at once can hurt performance, so card components must be kept lean and tested on low-end phones.
